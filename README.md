# Cosmic Odyssey 🧠✨
### 3D Deep Learning & AI/ML Engineer Developer Portfolio

An interactive, responsive 3D developer portfolio themed around high-dimensional mathematical representations and deep learning visualizations. Built with **React**, **Three.js / React Three Fiber**, and **Tailwind CSS**.

---

## 🌌 Visualizer Systems

The portfolio replaces traditional space backdrops with active, scroll-snapping WebGL mathematical models:

*   **Latent Space Data Cloud (Intro)**: A volumetric coordinate cloud of 1,000 glowing high-dimensional embeddings surrounding a pulsing feature core.
*   **Neural Network MLP (Expertise)**: A dense feedforward Multi-Layer Perceptron network with active weight pulses traversing the synapses.
*   **Self-Attention Matrix Grid (Projects)**: A token grid representation displaying arched Bezier curves mapping attention connection coordinates between feature vectors.
*   **Gradient Descent Loss Landscape (Experience)**: An undulating 3D wireframe loss landscape featuring a parameter optimizer ball converging on a local minimum.
*   **Decision Tree Classifier (Education)**: A branching dendrogram classifier graph illustrating recursive splits and feature nodes.
*   **Lorenz Attractor Chaos Orbit (Hobbies)**: A chaotic ribbon trail calculated using Lorenz differential equations with an orbit tracer loop.
*   **Autoencoder Latent Bottleneck (Contact)**: An hourglass bottleneck shape showing data compression and feature reconstruction.

## 🚀 Running Locally

Follow these steps to run the interactive dashboard on your machine:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/your-username/cosmic-portfolio.git
    cd cosmic-portfolio
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Start the development server**:
    ```bash
    npm run dev
    ```
    Open `http://localhost:5173` in your browser.

4.  **Build for production**:
    ```bash
    npm run build
    ```

## 📱 Responsiveness & Snapping

*   **Auto-Scroll Snapping**: Scrolling automatically snaps viewport transitions to keep content cards centered.
*   **Mobile Mode**: The camera target shifts dynamically based on viewport dimensions. On mobile and tablet screens, the 3D models center directly behind text layers for maximum space utilization.
